# Rules for every keywords_*.txt file
#  - One keyword or phrase per line. Lowercase. Lines starting with '#' are comments (headings are '# =====').
#  - WHOLE-WORD matching on the URL path words (and the link text). 'gri' matches /gri-index but never /grid or /agriculture.
#  - Every form must be listed ('policy' will NOT match 'policies'; 'annualreport' will NOT match 'annual report').
#    A trailing '+' was used when generating: it already expanded plural + joined forms, so you do not need to type them.
#  - File extensions (.html .aspx .php), 'default', 'index', and /en/ style folders are ignored before matching.
#
# DECISION ORDER for one link (first rule that matches wins):
#   1  first folder is a non-English language folder        (hardblock file, lang_block)  -> REJECT
#   2  hard-block phrase / word                             (hardblock file)              -> REJECT
#   3  core word or phrase (or regex)                       (core file)                   -> FOLLOW at any depth
#   4  last folder IS a hub and depth <= 3                  (hub file)                    -> FOLLOW (listing page)
#   5  block word / phrase                                  (block file)                  -> REJECT
#   6  a parent folder is a hub AND last folder has a hub-child word (hubchild file)      -> FOLLOW
#   7  nothing matched                                                                    -> REJECT
#
# keywords_block.txt  -  words that STOP a hub / hub-child link (news, press, products, careers, stock quote ...).
# A core word in the same link still wins (/sustainability/news/ is kept). Remove a word here if it blocks pages you need.
